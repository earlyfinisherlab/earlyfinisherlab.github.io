20 printable Halloween math crossword puzzles (cross-number) for grade 4.

Students solve each clue and write one digit per box. Because the answers cross, a wrong answer shows up at the crossing instead of at the answer key, so the page checks itself. No prep: print and hand out.

What's Included

  • 20 puzzles, one per page, ready to photocopy
  • 376 clues in total, 2-digit up to 4-digit answers, ordered Easy to Hard so the same pack stretches across a class
  • Grids grow from 6x6 to 8x8 as the set goes on
  • A complete answer key with every grid filled in
  • 27 pages, US Letter, black-and-white friendly
