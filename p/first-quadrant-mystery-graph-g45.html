15 printable first quadrant coordinate graphing mystery pictures for grades 4-5, each in 3 versions (45 graphing pages).

Students plot each ordered pair, connect the points in order, and a hidden picture appears — then they color it in. Every picture comes on a first-quadrant grid in whole numbers, one where each square is worth 5, and one where each square is worth 0.5, so the whole class draws the same picture at the level each student is ready for. No prep: print and hand out.

What's Included

  • 15 original mystery pictures, 45 pages of ordered pairs, each with a how-to-read box for its level
  • First Quadrant: axes 0 to 30, whole numbers
  • First Quadrant by Fives: axes 0 to 150, counting by fives
  • First Quadrant with Halves: axes 0 to 15 in steps of 0.5
  • Graph paper for each version (3 pages), so students plot on a full-size grid
  • 67 to 101 points per picture, ordered easiest to hardest within each version
  • 15 full-page color answer keys; one key checks all 3 versions of its picture
  • 66 pages, US Letter; worksheets print in black and white

Standards Practiced

  • CCSS 4.NF.C.6: Use decimal notation for fractions with denominators 10 or 100
  • CCSS 5.G.A.1: Use a pair of perpendicular number lines to locate points in the coordinate plane
  • CCSS 5.G.A.2: Graph points in the first quadrant of the coordinate plane

Good For

  • Sub plans and emergency filler
  • Math centers and review days
  • Differentiating one activity across a mixed class, and homeschool

How These Are Checked

Every ordered pair in this pack is plotted again by an independent program before it ships, which confirms that the points on each page draw exactly the picture in the answer key. No page has a point off the grid or out of order.
